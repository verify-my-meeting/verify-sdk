# Test fixtures

`*.vcon` files are the unformatted appendix B examples of
`draft-ietf-vcon-vcon-core-05`, downloaded on 2026-11-07 from
`https://raw.githubusercontent.com/ietf-wg-vcon/draft-ietf-vcon-vcon-core/refs/heads/main/examples/`.
`vcon_json_schema.json` is the informational JSON schema of appendix C from
the same repository. They are data for the round-trip tests and are not
part of the published package.
